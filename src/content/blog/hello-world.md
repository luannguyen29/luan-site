Most of what a system administrator learns ends up in closed tickets, chat threads and shell history. When the same problem comes back a year later, the fix has to be rediscovered.

This blog is where I'll write those things down: how I traced an incident through the logs, how a backup script is structured, what I check first when a container node misbehaves.

## What to expect

- Incident write-ups: symptom, investigation, root cause, fix.
- Scripts I use in production, with the reasoning behind them.
- Notes on Virtuozzo/OpenVZ, Linux hardening, mail and web stacks.

This site itself is a small example: built with Astro and served from Cloudflare's edge as static files.
